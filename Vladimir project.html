06_questions.md


Вопросы комиссии




Как приложение понимает ноту?
Микрофон записывает звук, программа находит частоту (по повторению сигнала) и по формуле 69 + 12·log₂(f/440) выбирает ближайшую ноту.


Что, если вокруг шумно?
Слишком тихие звуки приложение игнорирует. Лучше играть рядом с микрофоном. Фильтрацию шума можно добавить дальше.


Чем это лучше тюнера?
Тюнер только показывает ноту. Здесь есть ещё нотный стан и режим обучения с проверкой ответа.


Что можно улучшить?
Уроки по уровням, больше октав, сохранение прогресса и версия для магазинов приложений.
